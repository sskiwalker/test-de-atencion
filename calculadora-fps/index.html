Cómo se calcula (y por qué no hay FPS guardados)

Cada juego guarda su coste de frame, no su resultado: cuántos milisegundos de GPU y de CPU cuesta un fotograma a 1080p sobre el hardware de referencia. Los FPS de cualquier combinación salen de escalar ese coste. 

ms_GPU  = coste_GPU x preset x ray_tracing x (píxeles/1080p)^exp x (100/índice_GPU) / sesgo_motor
ms_CPU  = coste_CPU x (100/índice_CPU)
frame   = (ms_GPU^6 + ms_CPU^6)^(1/6)      <- mezcla suave: el cuello de botella manda, pero no del todo
FPS     = 1000 / frame,  luego VRAM, PCIe, RAM y tope del juego

índice_GPU = 1 / ( (1-w)/cómputo + w/ancho_de_banda )      w sube con la resolución
  cómputo  = shaders x 2 x reloj x eficiencia_arquitectura x ocupación
  ancho    = bus/8 x Gbps x multiplicador_de_caché

índice_CPU = IPC_arquitectura x reloj_del_CCD^0.75 x (1 + caché_L3) x núcleos x RAM x scheduler
